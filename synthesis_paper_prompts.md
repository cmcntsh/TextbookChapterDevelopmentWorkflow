# Synthesis Paper Prompts

These are prompts I used to draft a synthesis paper in a ChatGPT Work session using the other instruction Markdown (.md) files in this repository. I'm keeping them here for future reference

## Identify Source Passages

```
Please follow the instructions in the source text extract synthesis document and identify passages in these sources that address the question, "When evaluating or critiquing a piece of academic or scholarly writing, what elements should be considered and in what order?"
```

## Analyze Paraphrase Statements

```
Analyze the paraphrase statements for agreement, disagreement, themes, subtleties, and gaps
```
## Group the Analysis by Topic

```
Group the analysis by topic.
```

## Suggest an Outline

```
Suggest a synthesis writeup outline.
```

## Add Supporting Evidence to the Synthesis Outline

```
Please use your recommended organization and create the synthesis outline with supporting evidence
```

## Write the First Draft

```
Write the synthesis narrative first draft.
```

## Suggest a New Title

```
Can you suggest a title that is simpler and more catchy? I'd like the title to be less stiff and academic.
```

## Draft a Simpler Version

```
Please write a draft that uses your new title and format it as a Markdown (.md) file using the same naming conventions as the previous documents. The new draft should be about 2000 words in length excluding references, but not more. Synthesize sentiments where possible and appropriate, but keep parenthetical citations to original sources. It's not necessary to use a source-by-source development of the argument. Focus on synthesis of important points. The Gopen articles are good examples of the style and tone the new draft should have. The content from sections 3, 4, and 11 can be reduced significantly. I'd like the new draft to be easy to understand and approachable.
```

## Adjust Language in Narrative

```
Please create a new draft in a Markdown (.md) file. In the new draft, remove references to the "sources" from the narrative. Don't mention source authors by name in the narrative. Simply provide the recommendations and retain the parenthetical citations to the original source materials.
```

## Add AI Acknowledgement

```
Please create a new draft in a Markdown (.md) file. Please add an AI Acknowledgement section before the References section and describe how AI was used to help draft the document. Please add an APA parenthetical citation for ChatGPT to the AI acknowledgement section. Please add the APA reference for OpenAI to the references list.
```
